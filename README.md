# 📑 Smart Document Organizer IDP

AI-Powered Intelligent Document Processing & Data Extraction Platform.

## 🚀 Supported Document Types
- **KTP / Identity Card** (Indonesian Identity Card)
- **Passport** (International Passport MRZ Parser)
- **Invoice / Struk** (Retail & Commercial Invoices)
- **Vendor / Supply Chain** (Purchase Orders, Delivery Orders, B2B Invoices)
- **Business Card** (Kartu Nama)
- **General Document** (Surat / Dokumen Umum)

## 🛠️ Features
- **High-Precision PaddleOCR Engine**: 2D Spatial bounding box clustering.
- **Auto-Deskew**: Intelligent document rotation ($0.8^\circ - 8.0^\circ$ safe guard).
- **PII Data Masking**: Automatic regex masking of sensitive personal data before AI processing.
- **Financial Reconciliation Engine**: Subtotal, Tax Amount, Discount, and Total Amount math verification.
